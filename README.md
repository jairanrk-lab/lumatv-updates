# LumaTV Launcher: atualizações

Downloads diretos do APK do LumaTV Launcher (Android TV), para instalar fora da Play Store.

**Link fixo da versão mais recente:**
https://github.com/jairanrk-lab/lumatv-updates/releases/latest/download/LumaTV.apk

Como instalar na TV: abra o app Downloader, digite o link acima (ou o código curto) e siga o instalador. Se a TV pedir, permita "Instalar apps desconhecidos" para o Downloader.

Confira a integridade: o SHA-256 de cada versão está nas notas da release. O certificado de assinatura é sempre o mesmo (SHA-256 `91:C8:E0:DD:30:2E:CA:DD:67:F9:20:C2:18:78:C0:D2:0E:12:44:31:5E:07:D1:D9:15:57:3F:D3:BF:E2:52:98`). Se a TV recusar a atualização por conflito de assinatura, desinstale o LumaTV e instale de novo.
